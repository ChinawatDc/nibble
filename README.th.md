# nibble (สรุปภาษาไทย)

**nibble** คือ skill สำหรับ AI coding agent ที่ช่วยให้อ่าน context น้อยลงโดยคุณภาพไม่ลด มี skill เดียว และเลือกโหมดให้อัตโนมัติ 3 โหมด: **code**, **docs**, **chat** (โหมด chat ยังเป็นแบบทดลอง)

## ติดตั้ง
คัดลอก `SKILL.md` และโฟลเดอร์ `modes/` ไปไว้ในโฟลเดอร์ skill ของ agent เช่น `.claude/skills/nibble/`, `.cursor/skills/nibble/`, `.codex/skills/nibble/` หรือ `.agents/skills/nibble/` (ดูคำสั่งใน [README.md](./README.md))

## ผลเทส (เบื้องต้น จากเวอร์ชันก่อนหน้า)
> ⚠️ **v0.2.0 ใน repo นี้ยังไม่ได้ทดสอบ** ตัวเลขด้านล่างวัดจาก v0.1 ก่อนแก้ ซึ่งไม่ได้เก็บไว้ (ไม่มีสำเนาและไม่มี sha) `SKILL.md` และ `modes/chat.md` ถูกแก้หลังเทส ส่วน `modes/code.md` และ `modes/docs.md` ถูกแก้ระหว่างรัน บางรอบจึงอาจใช้ไฟล์โหมดคนละเวอร์ชัน v0.2.0 รอชุดเทสใหม่ที่ยากกว่าและล็อกแล้ว

ค่ามัธยฐาน total token, 15 งานสังเคราะห์, 3 รอบต่องาน (รวม 90 รอบ), QA ตรวจแบบไม่รู้ว่ารอบไหนใช้ skill
- **Code:** 76,915 → 42,632 (−44.6%) ลดลงทุกงาน
- **Docs:** 45,992 → 30,891 (−32.8%) แต่งานที่ต้องอ่านหลายส่วนเพิ่มขึ้น (d04 +7.6%, d05 +18.5%)
- **Chat:** 29,695 → 43,508 (**+46.5%**) ยังไม่แนะนำให้ใช้
- **คุณภาพ:** ผ่านทั้ง 90 รอบทั้งแบบใช้และไม่ใช้ skill แต่ชุดเทสง่ายเกินไป จึงบอกไม่ได้ว่าคุณภาพดีขึ้น

## ข้อควรรู้
